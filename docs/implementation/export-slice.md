# Business export checkpoint

Schema 27 adds the separate workspace export capability without expanding ordinary resource visibility. A closed collection catalog, bounded JSON pages, manifests and continuations compose the owning business operations. Contacts/Organizations and current/ended relationships, tags, CRM records/configuration/participants, Tasks, activities, templates/revisions, coordination rules and full scoped checklist instances preserve public stable IDs and values. Each collection requires its primary and dependent read grants; assigned visibility still filters individual records. The [format guide](../business-export.md) specifies projections, exclusions and live-page consistency.

HTTP/OpenAPI, CLI, MCP and browser preview/download use the same operation. The collector follows every continuation into a private file, validates request/response selection and workspace, and atomically publishes a new output only after success. Fetch/validation failures remove staging data; existing files are never overwritten. Four filesystem/response regression tests cover failure cleanup, private output, existing-file preservation, page bounds, repeated cursors, changed collection/parent/lifecycle, missing selection, wrong workspace and malformed records.

Review identified missing dependent grants being silently projected empty, omitted merged-contact history, coordination summaries without item mappings/rules, and browser selections resetting. Regressions reproduced the permission/history defects before correction. Alias-family history now intersects source/survivor visibility; coordination uses one owning transaction with batched instance/task projection. The collector's initial selection-continuity gap also failed its regression before being corrected. Both review axes found no remaining actionable issues.

Final full acceptance passed on upgraded and clean-install fixtures after all corrections. Export evidence includes all advertised collection shapes, multi-page reads, exact Unicode/formula-like strings and decimals, origin/custom definition IDs, missing versus assigned grants, current/ended relationships, merged alias scope, archive selection, revoked export permission between pages, module/foreign-workspace denial, all transports, retained browser selections, all-page collection and cleanup on real mid-export revocation. Static checks, 7 Rust tests and 12 Python tests passed; production images built successfully. Broader release gates remain in coverage.md.
