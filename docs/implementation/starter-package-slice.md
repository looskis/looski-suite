# Removable CRM starter checkpoint

Schema 22 records explicit General CRM version 1 installations and typed workspace-qualified references to 16 copied definitions. Installation is available through API/OpenAPI, CLI, MCP and SSR, requires CRM and Tasks configuration read/manage, and serializes with other workspace writes. Module enablement and deployment upgrades never install defaults. A removed package can be installed again with fresh identities.

The package contains Sales stages (New, Qualified, Proposal, Won, Lost), General deal statuses (Planned, Active, Completed), Note and Interaction activity types, a Follow-up task type, a contextual Review requirements task template, a Start delivery checklist and a status rule. A material transition into Active schedules the checklist through the existing durable job operation. All copied definitions remain ordinary editable workspace configuration.

Configuration modules now expose transaction-bound operations alongside their existing pool entry points. Installation and removal compose these owning operations, audit/history and retry records in one transaction; CRM performs no direct Tasks writes. Current grants and module state are checked before replay as well as fresh execution.

Removal archives untouched definitions, retains modified definitions, and preserves dependencies of active configuration. Dependencies include older revisions of active checklist and Tasks template heads because those revisions remain explicitly usable. Decisions are persisted and displayed individually. Existing business records, task instances, checklist instances, relationships, revision evidence and history are retained. Pending work referencing archived definitions becomes blocked when evaluated by the worker.

The dedicated journey passed late install/removal rollback, original-result retries, competing concurrent installations, reference constraints, current authority and disabled-module denial, retained business instances and queued work, customization/dependency retention, explicit reinstall, and browser draft handling. Review identified and corrected historical-revision dependencies and added direct CLI/MCP mutation coverage. Static/unit checks, full fresh-install and upgraded-database acceptance, the primary deployment update and gateway smoke all passed. Both standards and specification review findings are resolved. This checkpoint is not a first-release completion claim.
