Looski Suite development preview: prebuilt runtime containers, agent-friendly installation commands, Cloudflare tunnel/DNS provisioning, and an expiring browser owner setup link.

Follow INSTALL.md from this release's source revision. Release archives include corresponding repository source; all runtime images are pinned by registry digest. SHA256SUMS and GitHub artifact attestations accompany the archives.

This draft is not approved for publication. Before publishing, record clean installation and authenticated owner journeys on both supported architectures, anonymous image access, real Cloudflare provisioning/resume/DNS conflict checks, external SMTP delivery and callbacks, dependency/container and third-party-notice review, and encrypted snapshot/restore validation. Do not describe these checks as passed based only on unit tests or successful image builds.

This preview targets an existing macOS/Linux host or Linux server. Hosting purchases, registrar automation, email provider signup, automatic backup scheduling and automatic release upgrades are not included in the installer. See INSTALL.md for agent-assisted handoffs and supported recovery operations.
